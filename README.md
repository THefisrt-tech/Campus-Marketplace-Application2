# Campus Marketplace Application

A peer-to-peer campus marketplace application built in C# featuring user registration, basic authentication password hashing, item listing creation, and search/filtering capabilities.

## Features
- **User Authentication:** Account registration with password hash validation.
- **Listing Management:** Create and associate items with seller user accounts.
- **Search Engine:** Filter available listings by item title or category keywords.

## Tech Stack
- **Language:** C# (.NET 8.0 / .NET Core)
- **Framework:** .NET Console SDK

## Quickstart & Build Instructions

### Prerequisites
Make sure you have the [.NET SDK](https://dotnet.microsoft.com/download) installed.

### Build & Run (Terminal)
```bash
# Clone repository
git clone [https://github.com/THefisrt-tech/Campus-Marketplace.git](https://github.com/THefisrt-tech/Campus-Marketplace.git)
cd Campus-Marketplace

# Build and run
dotnet run
